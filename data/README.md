# Data layout

- `samples/`: 18 unmodified public ESC-50 WAVs (12 original viewer examples and 6 held-out examples), JSON metadata, and source attribution. These small demonstration assets are committed.
- `raw/`: the 240-clip six-class training dataset and its manifest, downloaded by `python -m training.prepare`. Not committed.
- `cache/`: extracted features, frozen PANNs prefixes, and the original AudioSet pretrained checkpoint. Not committed; regenerated by training.

Run `python scripts/download-samples.py` to restore missing demonstration WAVs. Preserve `samples/ESC50-LICENSE.txt`. Do not add private or sensitive research data to the repository.
