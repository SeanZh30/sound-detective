DS7400 · HOMEWORK 3

Does temporal information need a learned gate?

A controlled extension of the HW2 sound classifier on UrbanSound8K.

From 240 clips to 8,732

HW2 limitation

Whole-clip means and standard deviations discard within-recording temporal structure.

Dog barks, gunshots and other short events may benefit from local information.

Hypothesis before training

Combine global and four ordered segment representations. Learn when to rely on each.

Risk: more parameters, short-clip padding and gate saturation may hurt generalization.

Controlled protocol

10 classes10 official test folds4 models × 80 epochs × 10 folds

For each test fold: eight folds train, the next cyclic fold validates. Five sources span official folds: related clips are purged from training/validation to isolate sources, while every test clip remains.

Same SGD, batch size, hidden width and dropout. Select checkpoints only by validation loss.

New task and class set: these percentages are not comparable with HW2's six-class accuracy. One seed per fold; no test-driven tuning.

Evidence and interpretation

Learned gate minus HW2 MLP: +3.95 percentage points; higher accuracy in 9/10 folds.

Learned gate minus fixed fusion: -2.01 points; higher in 2/10 folds.

Learned gate minus concatenation: +1.35 points. The simplest temporal representation is an essential control.

Mean local gate: 0.767; saturated (<0.05 or >0.95): 49.9%.

Limits and next experiment

One seed per fold, correlated training splits, and different parameter counts limit the conclusions. Test-time segment reversal also changes positional feature distributions.

Gate saturation is a plausible failure mechanism, not a proven cause. Next: repeat seeds, add a capacity-matched global baseline, and test gentler gates and valid-duration segments using validation data.
