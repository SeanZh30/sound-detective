# 答辩前需要理解的内容

本项目由 AI 辅助实现。你需要亲自运行、阅读代码并练习解释，不能把生成的说明当作自己已经理解的证明。

## 整个系统在做什么

浏览器把音频交给 FastAPI。后端从音频波形提取 168 个数，用训练时保存的均值和标准差进行标准化，再把这些数输入 MLP，返回六个类别的概率。预测函数不读取文件名中的类别信息。

## 为什么不是直接输入 WAV 文件

WAV 是音频容器。五秒音频有很多采样点，而训练集只有 144 条，所以先用声音特征压缩输入。log-mel 表示不同频段的能量，MFCC 是对 log-mel 的进一步变换。每个频带/系数取时间上的均值与标准差，得到 64×2 + 20×2 = 168 个特征。代价是丢失了事件的时间顺序。

## MLP 长什么样

168 个输入 → 64 个隐藏单元 → ReLU → Dropout → 6 个输出。共有 168×64+64+64×6+6 = 11,206 个参数。

- Linear：计算 Wx+b。
- ReLU：负数变成零，正数保留，提供非线性。
- Dropout：训练时随机关闭一半隐藏单元，帮助减少过拟合；推理时关闭 dropout。
- 输出 logits：每个类别的原始分数。softmax 把它们转换成总和为 1 的分数。

## 一次训练更新

1. 取一批训练样本（最多 24 条）。
2. `zero_grad()` 清除上一批的梯度。
3. 前向传播得到 logits。
4. 交叉熵比较 logits 与真实标签，计算损失。
5. `loss.backward()` 根据链式法则计算每个参数的梯度。
6. `optimizer.step()` 使用带 momentum 的 SGD 更新参数。

最基础的更新公式是 w ← w − learning_rate × gradient。本项目再加 momentum 和 weight decay。一个 epoch 表示完整遍历训练集一次。

## train / validation / test 为什么分开

训练集学习参数，也用来学习标准化的均值与标准差。验证集挑选隐藏层大小、学习率、dropout 和训练轮数。测试集在这些选择结束后才评估。按 ESC-50 官方 folds 划分，防止同一原始录音的不同片段跨集合出现。

## 结果怎么解释

MLP 测试准确率 41/48 = 85.42%；逻辑回归为 36/48 = 75%。两者使用同样的特征和数据划分。MLP 的测试错误率更低，但测试集只有 48 条，不能说明它能识别任意声音。

最佳模型是第 8 个 epoch 保存的权重，训练继续到第 53 个 epoch，连续 45 个 epoch 没有更低的验证 loss 才停止。继续训练可能提高训练集准确率，却让验证损失变大，所以恢复最佳 checkpoint。

模型把两条狗叫误判为时钟滴答，也会混淆其他短促声音。查看混淆矩阵：行是真实类别，列是预测类别，对角线是正确结果。
